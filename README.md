## 从零到上线的完整流程

整个建站过程可以拆成十步，走熟了不到一小时：

1. 购买搬瓦工 VPS，支持支付宝付款；
2. 注册域名，推荐阿里云、腾讯云或 NameSilo，别在搬瓦工官网买，贵；
3. 登录 KiwiVM 后台选机房、装系统，推荐 Debian 12 或 Ubuntu 22.04；
4. SSH 连接 VPS，Windows 用 Xshell 或 PuTTY，Mac 和 Linux 用自带终端；
5. 安装宝塔面板，一行命令装好，装完选 LNMP 套件一键部署；
6. 在宝塔里添加网站、创建数据库；
7. 通过宝塔的文件管理远程下载 WordPress 压缩包，解压到站点目录；
8. 把域名 A 记录指向 VPS 的 IP 地址；
9. 浏览器访问域名，跟着 WordPress 安装向导填信息；
10. 用宝塔内置的 Let's Encrypt 一键部署 SSL 证书，让网站跑上 HTTPS。

新手最容易卡住的是第五步之前的环境搭建。用宝塔面板的话，终端里只输一行安装命令，之后全图形界面操作，命令行这一关基本就跳过去了。

## 几个容易踩的坑

**IP 被干扰。** 面向国内用户的站，VPS 的 IP 偶尔会被防火长城干扰，表现为访问时好时坏。遇到这种情况可以套一层 Cloudflare CDN 做缓冲，免费版就够用。

**CPU 用量。** 搬瓦工对 CPU 使用有严格限制，网站突然爆火、访问量暴增时，CPU 跟不上会被限速甚至暂停。建议定期去后台看 Detailed Statistics，经常超负荷就升配——后台支持自助升降级，补差价即可。

**多站点没问题。** 一台 VPS 可以同时跑多个网站，域名各自解析到同一个 IP，宝塔里分别建站就行。1GB 内存同时跑 2 到 3 个低流量站没什么压力，站点更多或流量更大再考虑升级配置。
